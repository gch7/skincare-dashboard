# 🌸 Skincare Dashboard

Personal skincare routine, organized by season.

## Dashboards

- 🌿 **[Estate](estate.html)** — routine senza Epiduo (3 giu → 4 lug, 5 ago → 14 set)
- 🌊 **[Mare](mare.html)** — vacanza 5 lug → 5 ago
- 💗 **[Standard](inverno.html)** — routine completa con Epiduo (da metà settembre)

## How to use

Open **[index.html](index.html)** — the landing page auto-detects today's date and highlights the right dashboard.

For best experience: open in Safari on iPhone → tap Share → Add to Home Screen.
